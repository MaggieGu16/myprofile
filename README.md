# Maggie Gu 个人主页

一个基于 GitHub Pages 的静态学术个人主页，用于展示个人简介、研究方向、技能、代表性论文、科研项目与学术著作。页面采用纯 HTML + CSS + 少量原生 JavaScript 实现，无需构建工具、无第三方依赖、无外部 CDN 资源。

## 线上预览

- 线上页面：<https://maggiegu16.github.io/myprofile/>
- 源码仓库：<https://github.com/MaggieGu16/myprofile>

## 目录结构

```text
myprofile/
├── index.html   # 页面结构、样式与交互（全部内容集中在此文件）
└── README.md    # 本说明文档
```

## 页面结构

- **顶部身份区**：姓名、身份说明、一句话研究定位、GitHub / 仓库外链，以及「中文 / English」语言切换。
- **章节导航**：关于我、研究方向、技能、基本信息、代表性论文、科研项目、学术著作、联系；点击可平滑跳转，滚动时高亮当前章节。
- **左侧信息栏**：基本信息、分类后的技能标签、联系入口。
- **右侧主内容**：关于我、研究方向与兴趣、代表性论文、科研项目、学术著作。
- **页脚与辅助交互**：外链、回到顶部按钮、键盘跳转链接。

## 中英文版本

页面采用**单文件双语**实现，仓库中只维护一份 `index.html`：

- 顶部「中文 / English」按钮切换全站文案，包括页面标题、浏览器标签与搜索摘要。
- 中文为源码中的默认文案；英文文案写在对应元素的 `data-en` 属性中，无障碍标签写在 `data-en-aria` 中。修改文案时两种语言需同步更新。
- 选择保存在浏览器本地（`localStorage`）；未保存过选择且浏览器语言为英文时，首次打开自动显示英文。
- 3 篇论文和 3 部著作的年份仍为 `202X`；中文题名的英文为直译并标注 `translated title`，同时保留原题名。如有官方英文题名，请替换后再发布。

## 本地预览

方式一：直接用浏览器打开 `index.html`。

方式二：在仓库目录启动本地服务（推荐，行为与线上一致）：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000/>。

## 部署到 GitHub Pages

1. 进入仓库 **Settings → Pages**。
2. **Source** 选择仓库的默认分支（当前为 `master`；如果以后改名，则选 `main`），目录选择 **/(root)**。
3. 保存后等待数十秒，线上地址 <https://maggiegu16.github.io/myprofile/> 会自动更新。

> 说明：`index.html` 必须位于仓库根目录。修改源码后需 `git add` → `git commit` → `git push`，线上页面才会同步更新；不要直接编辑 GitHub Pages 生成的页面。

## 常见修改位置

所有内容都在 `index.html` 中，可用编辑器搜索下列关键词快速定位：

| 想改的内容 | 搜索关键词 |
| --- | --- |
| 姓名、身份说明、一句话简介 | `hero-copy`、`subtitle`、`hero-summary` |
| 头像（当前为 🥗 emoji） | `class="avatar"` |
| 技能标签及分类 | `tag--focus`、`tag--method`、`tag--teach` |
| 地点、学历、任职信息 | `info-item` |
| 关于我 / 研究方向文字 | `id="about"`、`id="research"` |
| 论文、项目、著作条目 | `id="publications"`、`id="projects"`、`id="books"` |
| GitHub 等外部链接 | `hero-links`、`footer-links` |
| 英文文案 | `data-en`（正文）、`data-en-aria`（无障碍标签） |
| 配色与圆角 | `:root` 中的 CSS 变量 |

修改论文等项目时，建议只替换文字，保留 `.entry` / `.entry-title` / `.entry-meta` 结构，以免破坏排版。

## 设计与兼容性说明

- 延续原有青绿渐变、白色卡片、圆角和 emoji 图标的个人风格。
- 响应式：宽度 ≥ 900px 为双栏；< 900px 切为单栏；< 640px 收紧间距并将章节导航改为可横向滑动。
- 可访问性：语义化标签、键盘跳转链接、焦点样式、装饰性 emoji 不朗读。
- 兼容性：外链均带 `rel="noopener noreferrer"`；不依赖外部字体、图标库或脚本；支持 `prefers-reduced-motion` 与打印样式。
